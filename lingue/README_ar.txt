YAEC – Yet Another EME Calc 1.9
إعداد Costantino IC8TEM
==========================================

حاسبة لهواة الراديو الذين يعملون في الاتصال عبر القمر EME (أرض–قمر–أرض) من 50 ميغاهرتز إلى 23 cm (1296 ميغاهرتز): موقع القمر ونوافذ التوجيه وفق حدود هوائيك، وتخطيط الأيام ذات أفضل Dgrd، وميزانية وصلة EME بهوائيات ياغي أو بالأطباق، وضوضاء السماء والشمس، وقاعدة بيانات للكابلات المحورية، وأدلة عن EME. لأنظمة Windows وLinux وmacOS، بـ 37 لغة. النطاقات فوق 432 ميغاهرتز قيد الاستكمال، لكن DGRD تُحسب بالفعل حسابًا صحيحًا عند كل تردد.
المصدر والتنزيل: https://github.com/ic8tem/YAEC/releases

التثبيت – WINDOWS
1. نزّل YAEC-1.9-win-x64-setup.exe من صفحة Releases وشغّله. يثبّت YAEC في المستندات\YAEC دون صلاحيات المسؤول، مع اختصارات في قائمة "ابدأ" وعلى سطح المكتب، وبرنامج لإلغاء التثبيت.
2. إذا ظهر تحذير SmartScreen: "More info" ← "Run anyway".
3. دون تثبيت: استخرج YAEC-1.9-win-x64-portatile.zip في مجلد لديك صلاحية الكتابة فيه، ثم شغّل YAEC.exe.

التثبيت – LINUX
يعمل YAEC على Mono، بيئة تشغيل .NET الحرة.
- Debian وUbuntu وMint: نزّل yaec_1.9_amd64.deb وثبّته بالأمر
      sudo apt install ./yaec_1.9_amd64.deb
  (يثبّت Mono أيضًا). يُشغَّل YAEC من قائمة التطبيقات أو بالأمر "yaec".
- التوزيعات الأخرى: ثبّت Mono (Fedora: sudo dnf install mono-complete؛ Arch: sudo pacman -S mono؛ openSUSE: sudo zypper install mono-complete)، ثم استخرج YAEC-1.9-linux-x64-portatile.tar.gz (ARM: YAEC-1.9-linux-arm64-portatile.tar.gz, YAEC-1.9-linux-arm-portatile.tar.gz; Linux i686: YAEC-1.9-linux-x86-portatile.tar.gz; FreeBSD amd64: YAEC-1.9-freebsd-x64-portatile.tar.gz; OpenBSD amd64: YAEC-1.9-openbsd-x64-portatile.tar.gz; Fedora, openSUSE: yaec-1.9-1.noarch.rpm; Raspberry Pi OS 32 bit: yaec_1.9_armhf.deb; Windows ARM64: YAEC-1.9-win-arm64-setup.exe) وشغّل ./install.sh.

التثبيت – macOS (تجريبي)
1. ثبّت Mono لنظام macOS (https://www.mono-project.com/download/stable/) وXQuartz (https://www.xquartz.org).
2. افتح YAEC-1.9-osx-arm64.dmg (Apple Silicon) / YAEC-1.9-osx-x64.dmg (Intel) واسحب YAEC إلى مجلد التطبيقات. في المرة الأولى: انقر بزر الماوس الأيمن على YAEC ← فتح (التطبيق غير موقّع من Apple).

التحقق من الملفات المنزّلة (SHA-256)
يحتوي كل إصدار على SHA256SUMS.txt مع بصمة SHA-256 لكل حزمة. قارنها ببصمة الملف الذي نزّلته:
- Windows (PowerShell): Get-FileHash .\YAEC-1.9-win-x64-setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
إذا اختلفت القيمتان فلا تثبّت الملف: نزّله من جديد.

اللغة والبيانات
تُختار اللغة في أعلى النافذة الرئيسية. جميع بيانات البرنامج موجودة في المجلد "data": على Windows بجوار YAEC.exe، وعلى Linux في ~/.local/share/YAEC/data، وعلى macOS في ~/Library/Application Support/YAEC/data.
