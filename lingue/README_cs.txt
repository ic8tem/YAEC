YAEC – Yet Another EME Calc 1.6
autor Costantino IC8TEM
==========================================

Kalkulátor pro radioamatéry pracující přes EME (Země–Měsíc–Země) od 50 MHz po 23 cm (1296 MHz): poloha Měsíce a okna zaměření podle limitů vlastní antény, plánování dní s nejlepší Dgrd, bilance spojení EME s anténami yagi nebo parabolami, šum oblohy a Slunce, databáze koaxiálních kabelů a manuály o EME. Pro Windows, Linux a macOS, ve 36 jazycích. Pásma nad 432 MHz se dokončují, ale DGRD je již na každé frekvenci počítána správně.
Zdrojový kód a stažení: https://github.com/ic8tem/YAEC/releases

INSTALACE – WINDOWS
1. Stáhněte YAEC-1.6-win-x64-setup.exe ze stránky Releases a spusťte jej. Nainstaluje YAEC do Dokumenty\YAEC, bez administrátorských práv, se zástupci v nabídce Start a na ploše a s odinstalačním programem.
2. Pokud se objeví upozornění SmartScreen: "Další informace" → "Přesto spustit".
3. Bez instalace: rozbalte YAEC-1.6-win-x64-portatile.zip do složky, do které můžete zapisovat, a spusťte YAEC.exe.

INSTALACE – LINUX
YAEC běží s Mono, svobodným běhovým prostředím .NET.
- Debian, Ubuntu, Mint: stáhněte yaec_1.6_amd64.deb a nainstalujte jej příkazem
      sudo apt install ./yaec_1.6_amd64.deb
  (nainstaluje i Mono). YAEC se spouští z nabídky aplikací nebo příkazem "yaec".
- Jiné distribuce: nainstalujte Mono (Fedora: sudo dnf install mono-complete; Arch: sudo pacman -S mono; openSUSE: sudo zypper install mono-complete), rozbalte YAEC-1.6-linux-x64-portatile.tar.gz (ARM: YAEC-1.6-linux-arm64-portatile.tar.gz, YAEC-1.6-linux-arm-portatile.tar.gz) a spusťte ./install.sh.

INSTALACE – macOS (experimentální)
1. Nainstalujte Mono pro macOS (https://www.mono-project.com/download/stable/) a XQuartz (https://www.xquartz.org).
2. Otevřete YAEC-1.6-osx-arm64.dmg (Apple Silicon) / YAEC-1.6-osx-x64.dmg (Intel) a přetáhněte YAEC do složky Aplikace. Poprvé: pravé tlačítko na YAEC → Otevřít (aplikace není podepsána společností Apple).

KONTROLA STAŽENÝCH SOUBORŮ (SHA-256)
Každé vydání obsahuje SHA256SUMS.txt s otiskem SHA-256 každého balíčku. Porovnejte jej s otiskem staženého souboru:
- Windows (PowerShell): Get-FileHash .\YAEC-1.6-win-x64-setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
Pokud se obě hodnoty liší, soubor neinstalujte: stáhněte jej znovu.

JAZYK A DATA
Jazyk se volí nahoře na hlavní obrazovce. Všechna data programu jsou ve složce "data": ve Windows vedle YAEC.exe, na Linuxu v ~/.local/share/YAEC/data, na macOS v ~/Library/Application Support/YAEC/data.
