YAEC – Yet Another EME Calc 1.4
מאת Costantino IC8TEM
==========================================

מחשבון לחובבי רדיו העובדים ב-EME (כדור הארץ–ירח–כדור הארץ) בתדרים 50 עד 432 MHz: מיקום הירח וחלונות הכיוון בהתאם למגבלות האנטנה שלך, תכנון הימים עם ה-Dgrd הטוב ביותר, תקציב קישור EME, רעש השמיים והשמש, מסד נתונים של כבלים קואקסיאליים ומדריכים על EME. ל-Windows, Linux ו-macOS, ב-26 שפות.
קוד מקור והורדה: https://github.com/ic8tem/YAEC/releases

התקנה – WINDOWS
1. הורד את YAEC-1.4-Setup.exe מדף Releases והפעל אותו. הוא מתקין את YAEC בתיקייה מסמכים\YAEC, ללא הרשאות מנהל, עם קיצורי דרך בתפריט התחל ובשולחן העבודה, וכן תוכנית הסרה.
2. אם מופיעה אזהרת SmartScreen: "More info" ← "Run anyway".
3. ללא התקנה: חלץ את YAEC-1.4-windows-portable.zip לתיקייה שיש לך הרשאת כתיבה בה והפעל את YAEC.exe.

התקנה – LINUX
YAEC פועל על Mono, סביבת הריצה החופשית של .NET.
- Debian, Ubuntu, Mint: הורד את yaec_1.4_all.deb והתקן אותו באמצעות
      sudo apt install ./yaec_1.4_all.deb
  (מתקין גם את Mono). YAEC מופעל מתפריט היישומים או בפקודה "yaec".
- הפצות אחרות: התקן את Mono (Fedora: sudo dnf install mono-complete; Arch: sudo pacman -S mono; openSUSE: sudo zypper install mono-complete), חלץ את YAEC-1.4-linux.tar.gz והפעל את ./install.sh.

התקנה – macOS (ניסיוני)
1. התקן את Mono עבור macOS (https://www.mono-project.com/download/stable/) ואת XQuartz (https://www.xquartz.org).
2. פתח את YAEC-1.4-macOS.dmg וגרור את YAEC אל יישומים. בפעם הראשונה: לחיצה ימנית על YAEC ← פתח (היישום אינו חתום על ידי Apple).

בדיקת הקבצים שהורדו (SHA-256)
כל release כולל את SHA256SUMS.txt עם טביעת ה-SHA-256 של כל חבילה. השווה אותה לטביעה של הקובץ שהורדת:
- Windows (PowerShell): Get-FileHash .\YAEC-1.4-Setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
אם שני הערכים שונים, אל תתקין את הקובץ: הורד אותו מחדש.

שפה ונתונים
השפה נבחרת בחלק העליון של החלון הראשי. כל נתוני התוכנית נמצאים בתיקייה "data": ב-Windows לצד YAEC.exe, ב-Linux ב-~/.local/share/YAEC/data, וב-macOS ב-~/Library/Application Support/YAEC/data.
