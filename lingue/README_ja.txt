YAEC – Yet Another EME Calc 1.9.1
作者：Costantino IC8TEM
==========================================

50 MHz～23 cm（1296 MHz）で EME（地球–月–地球）通信を行うアマチュア無線家のための計算ツールです。自局アンテナの制約に応じた月の位置と指向可能時間帯、Dgrd が最良の日の計画、八木またはパラボラによる EME 回線計算、空の雑音と太陽雑音、同軸ケーブルのデータベース、EME のマニュアルを備えています。Windows、Linux、macOS 対応、37 言語。432 MHz より上のバンドは完成に向けて作業中ですが、DGRD はすでにすべての周波数で正しく計算されます。
ソースとダウンロード：https://github.com/ic8tem/YAEC/releases

インストール – WINDOWS
1. Releases ページから YAEC-1.9.1-win-x64-setup.exe をダウンロードして実行します。管理者権限なしで YAEC を ドキュメント\YAEC にインストールし、スタートメニューとデスクトップにショートカットを作成し、アンインストーラーも組み込みます。
2. SmartScreen の警告が表示された場合：「詳細情報」→「実行」。
3. インストールせずに使う場合：YAEC-1.9.1-win-x64-portatile.zip を書き込み可能なフォルダーに展開し、YAEC.exe を起動します。

インストール – LINUX
YAEC はフリーの .NET ランタイムである Mono で動作します。
- Debian、Ubuntu、Mint：yaec_1.9.1_amd64.deb をダウンロードし、次のコマンドでインストールします
      sudo apt install ./yaec_1.9.1_amd64.deb
  （Mono も同時にインストールされます）。YAEC はアプリケーションメニューから、またはコマンド「yaec」で起動します。
- その他のディストリビューション：Mono をインストールし（Fedora: sudo dnf install mono-complete、Arch: sudo pacman -S mono、openSUSE: sudo zypper install mono-complete）、YAEC-1.9.1-linux-x64-portatile.tar.gz (ARM: YAEC-1.9.1-linux-arm64-portatile.tar.gz, YAEC-1.9.1-linux-arm-portatile.tar.gz; Linux i686: YAEC-1.9.1-linux-x86-portatile.tar.gz; FreeBSD amd64: YAEC-1.9.1-freebsd-x64-portatile.tar.gz; OpenBSD amd64: YAEC-1.9.1-openbsd-x64-portatile.tar.gz; Alpine Linux: YAEC-1.9.1-alpine-x64-portatile.tar.gz, YAEC-1.9.1-alpine-arm64-portatile.tar.gz) を展開して ./install.sh を実行します。
- Fedora, openSUSE: yaec-1.9.1-1.noarch.rpm · Arch Linux, Manjaro: yaec-1.9.1-1-any.pkg.tar.zst · Slackware: yaec-1.9.1-noarch-1_ic8tem.txz · AppImage: YAEC-1.9.1-x86_64.AppImage, YAEC-1.9.1-aarch64.AppImage · Raspberry Pi OS 32 bit: yaec_1.9.1_armhf.deb · Windows ARM64: YAEC-1.9.1-win-arm64-setup.exe, YAEC-1.9.1-win-arm64-portatile.zip

インストール – macOS（試験的）
1. macOS 用 Mono（https://www.mono-project.com/download/stable/）と XQuartz（https://www.xquartz.org）をインストールします。
2. YAEC-1.9.1-osx-arm64.dmg (Apple Silicon) / YAEC-1.9.1-osx-x64.dmg (Intel) を開き、YAEC を「アプリケーション」にドラッグします。初回は YAEC を右クリック →「開く」を選びます（このアプリは Apple の署名を受けていません）。

自動更新
YAEC は起動時に GitHub で新しいバージョンを確認し、自動的に更新します（Windows、ポータブルの .tar.gz アーカイブ、AppImage、macOS アプリ）。その際 SHA-256 フィンガープリントを検証します。.deb, .rpm, Arch, Slackware のパッケージはシステムのパッケージマネージャーで更新します。YAEC は新しいバージョンを知らせ、GitHub のページを開きます。

ダウンロードしたファイルの確認（SHA-256）
各 release には、すべてのパッケージの SHA-256 ハッシュを記載した SHA256SUMS.txt が含まれています。ダウンロードしたファイルのハッシュと比較してください：
- Windows (PowerShell): Get-FileHash .\YAEC-1.9.1-win-x64-setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
2 つの値が異なる場合は、そのファイルをインストールせず、もう一度ダウンロードしてください。

言語とデータ
言語はメイン画面の上部で選択します。プログラムのすべてのデータは「data」フォルダーにあります。Windows では YAEC.exe と同じ場所、Linux では ~/.local/share/YAEC/data、macOS では ~/Library/Application Support/YAEC/data です。

ライセンス
YAEC は無料です。ライセンス本文はファイル LICENSE_ja.txt と、プログラムの「ライセンス」タブにあります。疑義がある場合はイタリア語版（LICENZA.txt）が優先します。
