YAEC – Yet Another EME Calc 1.8
제작: Costantino IC8TEM
==========================================

50 MHz~23 cm(1296 MHz)에서 EME(지구–달–지구) 교신을 하는 아마추어 무선사를 위한 계산기입니다: 자신의 안테나 한계에 따른 달의 위치와 지향 가능 시간대, Dgrd가 가장 좋은 날짜 계획, 야기 또는 접시 안테나를 사용한 EME 링크 버짓, 하늘 잡음과 태양 잡음, 동축 케이블 데이터베이스, EME 매뉴얼을 제공합니다. Windows, Linux, macOS용이며 37개 언어를 지원합니다. 432 MHz 이상의 밴드는 아직 완성 중이지만, DGRD는 이미 모든 주파수에서 올바르게 계산됩니다.
소스 및 다운로드: https://github.com/ic8tem/YAEC/releases

설치 – WINDOWS
1. Releases 페이지에서 YAEC-1.8-win-x64-setup.exe를 다운로드하여 실행합니다. 관리자 권한 없이 YAEC를 문서\YAEC에 설치하며, 시작 메뉴와 바탕 화면에 바로 가기를 만들고 제거 프로그램도 함께 설치합니다.
2. SmartScreen 경고가 나타나면: "추가 정보" → "실행".
3. 설치 없이 사용: YAEC-1.8-win-x64-portatile.zip을 쓰기 권한이 있는 폴더에 압축 해제하고 YAEC.exe를 실행합니다.

설치 – LINUX
YAEC는 자유 .NET 런타임인 Mono에서 동작합니다.
- Debian, Ubuntu, Mint: yaec_1.8_amd64.deb를 다운로드하여 다음 명령으로 설치합니다
      sudo apt install ./yaec_1.8_amd64.deb
  (Mono도 함께 설치됩니다). YAEC는 응용 프로그램 메뉴에서 또는 "yaec" 명령으로 실행합니다.
- 기타 배포판: Mono를 설치하고(Fedora: sudo dnf install mono-complete; Arch: sudo pacman -S mono; openSUSE: sudo zypper install mono-complete), YAEC-1.8-linux-x64-portatile.tar.gz (ARM: YAEC-1.8-linux-arm64-portatile.tar.gz, YAEC-1.8-linux-arm-portatile.tar.gz)의 압축을 푼 뒤 ./install.sh를 실행합니다.

설치 – macOS (실험적)
1. macOS용 Mono(https://www.mono-project.com/download/stable/)와 XQuartz(https://www.xquartz.org)를 설치합니다.
2. YAEC-1.8-osx-arm64.dmg (Apple Silicon) / YAEC-1.8-osx-x64.dmg (Intel)를 열고 YAEC를 응용 프로그램 폴더로 드래그합니다. 처음 실행할 때: YAEC를 오른쪽 클릭 → 열기 (이 앱은 Apple의 서명을 받지 않았습니다).

다운로드한 파일 확인 (SHA-256)
각 release에는 모든 패키지의 SHA-256 해시가 담긴 SHA256SUMS.txt가 포함되어 있습니다. 다운로드한 파일의 해시와 비교하십시오:
- Windows (PowerShell): Get-FileHash .\YAEC-1.8-win-x64-setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
두 값이 다르면 파일을 설치하지 말고 다시 다운로드하십시오.

언어와 데이터
언어는 메인 화면 상단에서 선택합니다. 프로그램의 모든 데이터는 "data" 폴더에 있습니다: Windows에서는 YAEC.exe 옆, Linux에서는 ~/.local/share/YAEC/data, macOS에서는 ~/Library/Application Support/YAEC/data입니다.

라이선스
YAEC는 무료입니다. 라이선스 전문은 LICENSE_ko.txt 파일과 프로그램의 라이선스 탭에 있습니다. 의문이 있을 경우 이탈리아어판(LICENZA.txt)이 우선합니다.
