YAEC – Yet Another EME Calc 1.8
av Costantino IC8TEM
==========================================

Kalkulator for radioamatører som kjører EME (Jord–Måne–Jord) fra 50 MHz til 23 cm (1296 MHz): månens posisjon og retningsvinduer innenfor grensene til din egen antenne, planlegging av dagene med best Dgrd, linkbudsjett for EME med yagi eller parabol, himmel- og solstøy, database over koaksialkabler og håndbøker om EME. For Windows, Linux og macOS, på 37 språk. Båndene over 432 MHz er under ferdigstilling, men DGRD beregnes allerede riktig på alle frekvenser.
Kildekode og nedlasting: https://github.com/ic8tem/YAEC/releases

INSTALLASJON – WINDOWS
1. Last ned YAEC-1.8-win-x64-setup.exe fra Releases-siden og kjør den. Den installerer YAEC i Dokumenter\YAEC, uten administratorrettigheter, med snarveier i Start-menyen og på skrivebordet, og med et avinstalleringsprogram.
2. Hvis SmartScreen-advarselen vises: «Mer informasjon» → «Kjør likevel».
3. Uten installasjon: pakk ut YAEC-1.8-win-x64-portatile.zip i en mappe du kan skrive i, og start YAEC.exe.

INSTALLASJON – LINUX
YAEC kjører på Mono, den frie .NET-kjøretiden.
- Debian, Ubuntu, Mint: last ned yaec_1.8_amd64.deb og installer den med
      sudo apt install ./yaec_1.8_amd64.deb
  (installerer også Mono). YAEC startes fra programmenyen eller med kommandoen «yaec».
- Andre distribusjoner: installer Mono (Fedora: sudo dnf install mono-complete; Arch: sudo pacman -S mono; openSUSE: sudo zypper install mono-complete), pakk ut YAEC-1.8-linux-x64-portatile.tar.gz (ARM: YAEC-1.8-linux-arm64-portatile.tar.gz, YAEC-1.8-linux-arm-portatile.tar.gz) og kjør ./install.sh.

INSTALLASJON – macOS (eksperimentell)
1. Installer Mono for macOS (https://www.mono-project.com/download/stable/) og XQuartz (https://www.xquartz.org).
2. Åpne YAEC-1.8-osx-arm64.dmg (Apple Silicon) / YAEC-1.8-osx-x64.dmg (Intel) og dra YAEC til Programmer. Første gang: høyreklikk på YAEC → Åpne (appen er ikke signert av Apple).

KONTROLL AV NEDLASTEDE FILER (SHA-256)
Hver release inneholder SHA256SUMS.txt med SHA-256-sjekksummen for hver pakke. Sammenlign den med sjekksummen for den nedlastede filen:
- Windows (PowerShell): Get-FileHash .\YAEC-1.8-win-x64-setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
Hvis de to verdiene er forskjellige, skal du ikke installere filen: last den ned på nytt.

SPRÅK OG DATA
Språket velges øverst i hovedvinduet. Alle programmets data ligger i mappen «data»: i Windows ved siden av YAEC.exe, i Linux i ~/.local/share/YAEC/data, i macOS i ~/Library/Application Support/YAEC/data.

LISENS
YAEC er gratis; lisensteksten står i filen LICENSE_nb.txt og i fanen LISENS i programmet. Ved tvil gjelder den italienske versjonen (LICENZA.txt).
