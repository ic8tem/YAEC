YAEC – Yet Another EME Calc 1.9
opracował Costantino IC8TEM
==========================================

Kalkulator dla krótkofalowców pracujących przez EME (Ziemia–Księżyc–Ziemia) od 50 MHz do 23 cm (1296 MHz): pozycja Księżyca i okna nakierowania zgodne z ograniczeniami własnej anteny, planowanie dni z najlepszą Dgrd, bilans łączności EME z antenami Yagi lub czaszami, szum nieba i Słońca, baza danych kabli koncentrycznych oraz podręczniki o EME. Dla systemów Windows, Linux i macOS, w 37 językach. Pasma powyżej 432 MHz są w trakcie uzupełniania, ale DGRD jest już poprawnie obliczana dla każdej częstotliwości.
Kod źródłowy i pliki do pobrania: https://github.com/ic8tem/YAEC/releases

INSTALACJA – WINDOWS
1. Pobierz YAEC-1.9-win-x64-setup.exe ze strony Releases i uruchom go. Instaluje YAEC w Dokumenty\YAEC, bez uprawnień administratora, ze skrótami w menu Start i na pulpicie oraz z programem odinstalowującym.
2. Jeśli pojawi się ostrzeżenie SmartScreen: „Więcej informacji” → „Uruchom mimo to”.
3. Bez instalacji: rozpakuj YAEC-1.9-win-x64-portatile.zip do folderu, w którym możesz zapisywać, i uruchom YAEC.exe.

INSTALACJA – LINUX
YAEC działa z Mono, wolnym środowiskiem uruchomieniowym .NET.
- Debian, Ubuntu, Mint: pobierz yaec_1.9_amd64.deb i zainstaluj go poleceniem
      sudo apt install ./yaec_1.9_amd64.deb
  (instaluje również Mono). YAEC uruchamia się z menu aplikacji lub poleceniem "yaec".
- Inne dystrybucje: zainstaluj Mono (Fedora: sudo dnf install mono-complete; Arch: sudo pacman -S mono; openSUSE: sudo zypper install mono-complete), rozpakuj YAEC-1.9-linux-x64-portatile.tar.gz (ARM: YAEC-1.9-linux-arm64-portatile.tar.gz, YAEC-1.9-linux-arm-portatile.tar.gz; Linux i686: YAEC-1.9-linux-x86-portatile.tar.gz; FreeBSD amd64: YAEC-1.9-freebsd-x64-portatile.tar.gz) i uruchom ./install.sh.

INSTALACJA – macOS (eksperymentalna)
1. Zainstaluj Mono dla macOS (https://www.mono-project.com/download/stable/) i XQuartz (https://www.xquartz.org).
2. Otwórz YAEC-1.9-osx-arm64.dmg (Apple Silicon) / YAEC-1.9-osx-x64.dmg (Intel) i przeciągnij YAEC do folderu Aplikacje. Za pierwszym razem: kliknij prawym przyciskiem YAEC → Otwórz (aplikacja nie jest podpisana przez Apple).

SPRAWDZANIE POBRANYCH PLIKÓW (SHA-256)
Każde wydanie zawiera plik SHA256SUMS.txt z sumą SHA-256 każdego pakietu. Porównaj ją z sumą pobranego pliku:
- Windows (PowerShell): Get-FileHash .\YAEC-1.9-win-x64-setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
Jeśli obie wartości się różnią, nie instaluj pliku: pobierz go ponownie.

JĘZYK I DANE
Język wybiera się u góry ekranu głównego. Wszystkie dane programu znajdują się w folderze "data": w Windows obok YAEC.exe, w Linuksie w ~/.local/share/YAEC/data, w macOS w ~/Library/Application Support/YAEC/data.
