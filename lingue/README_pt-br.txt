YAEC – Yet Another EME Calc 1.6
por Costantino IC8TEM
==========================================

Calculadora para radioamadores que operam em EME (Terra–Lua–Terra) de 50 MHz aos 23 cm (1296 MHz): posição da Lua e janelas de apontamento segundo os limites da própria antena, planejamento dos dias com a melhor Dgrd, balanço do enlace EME com yagis ou parabólicas, ruído do céu e do Sol, banco de dados de cabos coaxiais e manuais sobre EME. Para Windows, Linux e macOS, em 36 idiomas. As bandas acima de 432 MHz estão em fase de conclusão, mas a DGRD já é calculada corretamente em cada frequência.
Código-fonte e download: https://github.com/ic8tem/YAEC/releases

INSTALAÇÃO – WINDOWS
1. Baixe YAEC-1.6-win-x64-setup.exe da página Releases e execute-o. Ele instala o YAEC em Documentos\YAEC, sem direitos de administrador, com os atalhos no menu Iniciar e na área de trabalho e o programa de desinstalação.
2. Se aparecer o aviso do SmartScreen: "Mais informações" → "Executar assim mesmo".
3. Sem instalação: extraia YAEC-1.6-win-x64-portatile.zip em uma pasta em que você possa gravar e inicie YAEC.exe.

INSTALAÇÃO – LINUX
O YAEC funciona com o Mono, o runtime .NET livre.
- Debian, Ubuntu, Mint: baixe yaec_1.6_amd64.deb e instale-o com
      sudo apt install ./yaec_1.6_amd64.deb
  (instala também o Mono). O YAEC é iniciado pelo menu de aplicativos ou com o comando "yaec".
- Outras distribuições: instale o Mono (Fedora: sudo dnf install mono-complete; Arch: sudo pacman -S mono; openSUSE: sudo zypper install mono-complete), extraia YAEC-1.6-linux-x64-portatile.tar.gz (ARM: YAEC-1.6-linux-arm64-portatile.tar.gz, YAEC-1.6-linux-arm-portatile.tar.gz) e execute ./install.sh.

INSTALAÇÃO – macOS (experimental)
1. Instale o Mono para macOS (https://www.mono-project.com/download/stable/) e o XQuartz (https://www.xquartz.org).
2. Abra YAEC-1.6-osx-arm64.dmg (Apple Silicon) / YAEC-1.6-osx-x64.dmg (Intel) e arraste o YAEC para Aplicativos. Na primeira vez: clique com o botão direito em YAEC → Abrir (o app não é assinado pela Apple).

VERIFICAÇÃO DOS ARQUIVOS BAIXADOS (SHA-256)
Cada release contém SHA256SUMS.txt com a impressão digital SHA-256 de cada pacote. Compare-a com a do arquivo baixado:
- Windows (PowerShell): Get-FileHash .\YAEC-1.6-win-x64-setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
Se os dois valores forem diferentes, não instale o arquivo: baixe-o novamente.

IDIOMA E DADOS
O idioma é escolhido no alto da tela principal. Todos os dados do programa ficam na pasta "data": no Windows ao lado de YAEC.exe, no Linux em ~/.local/share/YAEC/data, no macOS em ~/Library/Application Support/YAEC/data.
