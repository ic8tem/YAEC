YAEC – Yet Another EME Calc 1.9.6
автор: Costantino IC8TEM
==========================================

Калькулятор для радиолюбителей, работающих через EME (Земля–Луна–Земля) в диапазонах от 50 МГц до 23 cm (1296 МГц): положение Луны и окна наведения с учётом ограничений вашей антенны, планирование дней с лучшим Dgrd, энергетический бюджет EME-радиолинии с Яги или параболическими антеннами, шумы неба и Солнца, база данных коаксиальных кабелей и руководства по EME. Для Windows, Linux и macOS, на 37 языках. Диапазоны выше 432 МГц находятся в стадии доработки, но DGRD уже правильно рассчитывается на любой частоте.
Исходный код и загрузка: https://github.com/ic8tem/YAEC/releases

УСТАНОВКА – WINDOWS
1. Скачайте YAEC-1.9.6-windows-x64-setup.exe со страницы Releases и запустите его. Он устанавливает YAEC в Документы\YAEC без прав администратора, с ярлыками в меню «Пуск» и на рабочем столе, а также с программой удаления.
2. Если появится предупреждение SmartScreen: «Подробнее» → «Выполнить в любом случае».
3. Без установки: распакуйте YAEC-1.9.6-windows-x64-portatile.zip в папку, в которую у вас есть право записи, и запустите YAEC.exe.

УСТАНОВКА – LINUX
YAEC работает в Mono — свободной среде выполнения .NET.
- Debian, Ubuntu, Mint: скачайте yaec_1.9.6_amd64.deb и установите его командой
      sudo apt install ./yaec_1.9.6_amd64.deb
  (заодно устанавливается и Mono). YAEC запускается из меню приложений или командой «yaec».
- Другие дистрибутивы: установите Mono (Fedora: sudo dnf install mono-complete; Arch: sudo pacman -S mono; openSUSE: sudo zypper install mono-complete), распакуйте YAEC-1.9.6-linux-x64.tar.gz (ARM: YAEC-1.9.6-linux-arm64.tar.gz, YAEC-1.9.6-linux-armv7l.tar.gz; Linux i686: YAEC-1.9.6-linux-x86.tar.gz; FreeBSD amd64: YAEC-1.9.6-freebsd-x64.tar.gz; OpenBSD amd64: YAEC-1.9.6-openbsd-x64.tar.gz; Alpine Linux: YAEC-1.9.6-alpine-x64.tar.gz, YAEC-1.9.6-alpine-arm64.tar.gz) и запустите ./install.sh.
- Fedora, openSUSE: yaec-1.9.6.x86_64.rpm · Arch Linux, Manjaro: yaec-1.9.6-1-x86_64.pkg.tar.zst · Slackware: yaec-1.9.6-x86_64-1_ic8tem.txz · AppImage: YAEC-1.9.6-x86_64.AppImage, YAEC-1.9.6-aarch64.AppImage · Raspberry Pi OS 32 bit: yaec_1.9.6_armhf.deb · Windows ARM64: YAEC-1.9.6-windows-arm64-setup.exe, YAEC-1.9.6-windows-arm64-portatile.zip

УСТАНОВКА – macOS (экспериментально)
1. Установите Mono для macOS (https://www.mono-project.com/download/stable/) и XQuartz (https://www.xquartz.org).
2. Откройте YAEC-1.9.6-mac-apple-silicon.dmg (Apple Silicon) / YAEC-1.9.6-mac-intel.dmg (Intel) и перетащите YAEC в папку «Программы». При первом запуске: щелчок правой кнопкой по YAEC → «Открыть» (приложение не подписано Apple).

АВТОМАТИЧЕСКИЕ ОБНОВЛЕНИЯ
При запуске YAEC проверяет на GitHub, есть ли новая версия, и обновляется сам (Windows, переносные архивы .tar.gz, AppImage, приложение для macOS), проверяя отпечаток SHA-256. Пакеты .deb, .rpm, Arch, Slackware обновляются менеджером пакетов системы: YAEC сообщает о новой версии и открывает страницу GitHub.

ПРОВЕРКА СКАЧАННЫХ ФАЙЛОВ (SHA-256)
Каждый релиз содержит SHA256SUMS.txt с хешем SHA-256 каждого пакета. Сравните его с хешем скачанного файла:
- Windows (PowerShell): Get-FileHash .\YAEC-1.9.6-windows-x64-setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
Если значения не совпадают, не устанавливайте файл: скачайте его заново.

ЯЗЫК И ДАННЫЕ
Язык выбирается в верхней части главного окна. Все данные программы хранятся в папке «data»: в Windows рядом с YAEC.exe, в Linux в ~/.local/share/YAEC/data, в macOS в ~/Library/Application Support/YAEC/data.

ЛИЦЕНЗИЯ
YAEC бесплатен; текст лицензии находится в файле LICENSE_ru.txt и на вкладке ЛИЦЕНЗИЯ в программе. В случае сомнений приоритет имеет итальянская версия (LICENZA.txt).

Новая вкладка «Луна над миром» (высота Луны над сушей всего мира, станция DX одним щелчком, состояние вашей антенны); руководство разделено на «ПОДРОБНОЕ РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ» и «ТЕОРИЯ И СОВЕТЫ ПО EME»; группы «Справка и инструменты» и «Credits and thanks»; вкладка «Экспорт расчётов в Excel»; запаса по виду связи больше нет: S/N в полосе 2500 Hz с типичным порогом в качестве ориентира, а пределы JT65 — в руководстве; в руководстве также таблица Q65 для TX1 – TX6, вращение Faraday и краткое изложение статьи SM5BSZ; таблицу кабелей можно сортировать по потерям, добавлены новые кабели Messi & Paoloni, SSB (SeaTex для морской среды, Aircom Premium), Belden и Tasker; в полях с единицами больше не остаётся лишнего текста.
