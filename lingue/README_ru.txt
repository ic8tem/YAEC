YAEC – Yet Another EME Calc 1.3
автор: Costantino IC8TEM
==========================================

Калькулятор для радиолюбителей, работающих через EME (Земля–Луна–Земля) в диапазонах от 50 до 432 МГц: положение Луны и окна наведения с учётом ограничений вашей антенны, планирование дней с лучшим Dgrd, энергетический бюджет EME-радиолинии, шумы неба и Солнца, база данных коаксиальных кабелей и руководства по EME. Для Windows, Linux и macOS, на 26 языках.
Исходный код и загрузка: https://github.com/ic8tem/YAEC/releases

УСТАНОВКА – WINDOWS
1. Скачайте YAEC-1.3-Setup.exe со страницы Releases и запустите его. Он устанавливает YAEC в Документы\YAEC без прав администратора, с ярлыками в меню «Пуск» и на рабочем столе, а также с программой удаления.
2. Если появится предупреждение SmartScreen: «Подробнее» → «Выполнить в любом случае».
3. Без установки: распакуйте YAEC-1.3-windows-portable.zip в папку, в которую у вас есть право записи, и запустите YAEC.exe.

УСТАНОВКА – LINUX
YAEC работает в Mono — свободной среде выполнения .NET.
- Debian, Ubuntu, Mint: скачайте yaec_1.3_all.deb и установите его командой
      sudo apt install ./yaec_1.3_all.deb
  (заодно устанавливается и Mono). YAEC запускается из меню приложений или командой «yaec».
- Другие дистрибутивы: установите Mono (Fedora: sudo dnf install mono-complete; Arch: sudo pacman -S mono; openSUSE: sudo zypper install mono-complete), распакуйте YAEC-1.3-linux.tar.gz и запустите ./install.sh.

УСТАНОВКА – macOS (экспериментально)
1. Установите Mono для macOS (https://www.mono-project.com/download/stable/) и XQuartz (https://www.xquartz.org).
2. Откройте YAEC-1.3-macOS.dmg и перетащите YAEC в папку «Программы». При первом запуске: щелчок правой кнопкой по YAEC → «Открыть» (приложение не подписано Apple).

ПРОВЕРКА СКАЧАННЫХ ФАЙЛОВ (SHA-256)
Каждый релиз содержит SHA256SUMS.txt с хешем SHA-256 каждого пакета. Сравните его с хешем скачанного файла:
- Windows (PowerShell): Get-FileHash .\YAEC-1.3-Setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
Если значения не совпадают, не устанавливайте файл: скачайте его заново.

ЯЗЫК И ДАННЫЕ
Язык выбирается в верхней части главного окна. Все данные программы хранятся в папке «data»: в Windows рядом с YAEC.exe, в Linux в ~/.local/share/YAEC/data, в macOS в ~/Library/Application Support/YAEC/data.

ЛИЦЕНЗИЯ
YAEC бесплатен; текст лицензии находится в файле LICENSE_ru.txt и на вкладке ЛИЦЕНЗИЯ в программе. В случае сомнений приоритет имеет итальянская версия (LICENZA.txt).
