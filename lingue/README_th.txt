YAEC – Yet Another EME Calc 1.9
โดย Costantino IC8TEM
==========================================

เครื่องคำนวณสำหรับนักวิทยุสมัครเล่นที่ทำ EME (โลก–ดวงจันทร์–โลก) ตั้งแต่ 50 MHz ถึง 23 cm (1296 MHz): ตำแหน่งดวงจันทร์และช่วงเวลาการชี้ภายในขีดจำกัดของสายอากาศของคุณเอง การวางแผนวันที่มี Dgrd ดีที่สุด บัดเจ็ตลิงก์ EME สำหรับยากิหรือจาน สัญญาณรบกวนจากท้องฟ้าและดวงอาทิตย์ ฐานข้อมูลสายโคแอกซ์ และคู่มือเกี่ยวกับ EME สำหรับ Windows, Linux และ macOS ใน 37 ภาษา แบนด์ที่สูงกว่า 432 MHz ยังอยู่ระหว่างการพัฒนาให้สมบูรณ์ แต่ DGRD คำนวณได้ถูกต้องแล้วที่ทุกความถี่
ซอร์สโค้ดและการดาวน์โหลด: https://github.com/ic8tem/YAEC/releases

การติดตั้ง – WINDOWS
1. ดาวน์โหลด YAEC-1.9-win-x64-setup.exe จากหน้า Releases แล้วเรียกใช้ ตัวติดตั้งจะติดตั้ง YAEC ไว้ใน Documents\YAEC โดยไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ พร้อมทางลัดในเมนู Start และบนเดสก์ท็อป และโปรแกรมถอนการติดตั้ง
2. หากมีคำเตือนของ SmartScreen ปรากฏ: "More info" → "Run anyway"
3. แบบไม่ต้องติดตั้ง: แตกไฟล์ YAEC-1.9-win-x64-portatile.zip ลงในโฟลเดอร์ที่คุณเขียนได้ แล้วเรียกใช้ YAEC.exe

การติดตั้ง – LINUX
YAEC ทำงานบน Mono ซึ่งเป็นรันไทม์ .NET แบบเสรี
- Debian, Ubuntu, Mint: ดาวน์โหลด yaec_1.9_amd64.deb แล้วติดตั้งด้วย
      sudo apt install ./yaec_1.9_amd64.deb
  (คำสั่งนี้ติดตั้ง Mono ด้วย) เรียกใช้ YAEC จากเมนูแอปพลิเคชันหรือด้วยคำสั่ง "yaec"
- ดิสทริบิวชันอื่น: ติดตั้ง Mono (Fedora: sudo dnf install mono-complete; Arch: sudo pacman -S mono; openSUSE: sudo zypper install mono-complete) แตกไฟล์ YAEC-1.9-linux-x64-portatile.tar.gz (ARM: YAEC-1.9-linux-arm64-portatile.tar.gz, YAEC-1.9-linux-arm-portatile.tar.gz) แล้วเรียกใช้ ./install.sh

การติดตั้ง – macOS (ทดลอง)
1. ติดตั้ง Mono สำหรับ macOS (https://www.mono-project.com/download/stable/) และ XQuartz (https://www.xquartz.org)
2. เปิด YAEC-1.9-osx-arm64.dmg (Apple Silicon) / YAEC-1.9-osx-x64.dmg (Intel) แล้วลาก YAEC ไปไว้ใน Applications ครั้งแรก: คลิกขวาที่ YAEC → Open (แอปไม่ได้ลงนามโดย Apple)

การตรวจสอบไฟล์ที่ดาวน์โหลด (SHA-256)
ทุกรุ่นที่เผยแพร่มีไฟล์ SHA256SUMS.txt ที่มีค่าแฮช SHA-256 ของแต่ละแพ็กเกจ ให้เปรียบเทียบกับค่าแฮชของไฟล์ที่ดาวน์โหลด:
- Windows (PowerShell): Get-FileHash .\YAEC-1.9-win-x64-setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
หากค่าทั้งสองไม่ตรงกัน อย่าติดตั้งไฟล์นั้น: ให้ดาวน์โหลดใหม่

ภาษาและข้อมูล
เลือกภาษาได้ที่ด้านบนของหน้าจอหลัก ข้อมูลทั้งหมดของโปรแกรมเก็บอยู่ในโฟลเดอร์ "data": บน Windows อยู่ข้าง YAEC.exe บน Linux อยู่ใน ~/.local/share/YAEC/data บน macOS อยู่ใน ~/Library/Application Support/YAEC/data

ประวัติเวอร์ชัน
เวอร์ชันก่อน 1.0 เรียกว่า beta
- 1.9 - แท็บใหม่ ขอบฟ้าของฉัน (สด): ขอบฟ้าจากภูมิประเทศคำนวณจากข้อมูล SRTM1 พร้อมความโค้งของโลกและการหักเห บนพื้นหลัง ทรงกลมฟ้า ในหนึ่งในสามสเกลสี เส้นทางดวงจันทร์ สิ่งกีดขวางหลักพร้อมชื่อจาก OpenStreetMap และนาทีของดวงจันทร์ที่เสียไป; ช่องเลือกเพื่อใช้ภูมิประเทศเป็นมุมเงยต่ำสุดทั้งโปรแกรม; แผนที่สัญญาณรบกวนท้องถิ่นตาม NJ9R พร้อม ⚠ ในชั่วโมงที่ดวงจันทร์อยู่ในทิศที่มีสัญญาณรบกวน; แท็บใหม่ สถานีที่ควรลอง (การวางแผน) แนวคิดจาก Matteo IW5DHN: สถานีที่ใช้งานในแชท N0UK เรียงตามดัชนี 0 ถึง 100; ช่องตัวเลขที่มีลูกศรวางเคียงกัน แท็บรูปเม็ดยา และชุดสีใหม่สามชุดจาก IP-TRX-CTRL
- 1.8 - ภาษาใหม่: สโลวัก (รวม 37 ภาษา) พร้อมคู่มือ README และใบอนุญาต ความกว้างลำคลื่นเดียวทั้งโปรแกรม: 0.93·√(41253/G) สำหรับยากิ (กฎของ Kraus ที่แก้ด้วยการจำลอง NEC ของ W4RNL เหมือนใน YA-MS) และ 70·λ/D สำหรับจาน (IZ0JNY) แทน √(32000/G) ที่ไม่มีแหล่งอ้างอิงใน DGRD ตามความถี่ ปรับปรุงคู่มือด้วยสูตรใหม่และตัวอย่างการชี้ บน macOS ตัวเปิดโปรแกรมจะเปิด XQuartz เอง เขียนเวอร์ชัน Mono ลงบันทึก และเตือนเมื่อ YAEC เปิดไม่ได้ การนำเสนอใน README มีภาษาโปรตุเกส ตุรกี เช็ก สโลวัก จีน ญี่ปุ่น และเกาหลีด้วย แก้คำแปลภาษาไทย โรมาเนีย กรีก โปรตุเกสบราซิล โปแลนด์ เช็ก และฮังการี
- 1.7 - ภาษาใหม่แปดภาษา: โปรตุเกสแบบบราซิล ไทย จีนตัวเต็ม โปแลนด์ เช็ก โรมาเนีย กรีก และฮังการี (รวม 36 ภาษา) พร้อมคู่มือและ README; ในบัดเจ็ต EME ยากิและบัดเจ็ต EME จาน มีการคำนวณเอคโค่ของสถานีตัวเอง (ฉันส่งและรับเอคโค่ของตัวเอง); จานแบบ prime focus หรือ offset (W2IMU); ที่ 1296 MHz กับจาน การสูญเสียจากโพลาไรเซชันวงกลมของฟีดจริง (KA1GT); ในตรวจสอบการคำนวณ เลือกได้ระหว่างบัดเจ็ต EME ยากิและบัดเจ็ต EME จาน; สูตรของ DGRD ตามความถี่เขียนแบบในโปรแกรมแก้ไขสมการ; คู่มือ: การหมุนฟาราเดย์ที่ 1296 MHz ตาม ITU-R P.531 การสูญเสียโพลาไรเซชันที่ 23 cm (Hagfors) และโพลาไรเซชันวงกลมใน 23 cm
- 1.6 - แบนด์ 902 MHz และ 23 cm (1296 และ 1298 MHz) ทั่วทั้งโปรแกรม โดยมีทุกแบนด์ในรายการแบบเลื่อนลงของ MHz; แท็บบัดเจ็ต EME เปลี่ยนเป็นบัดเจ็ต EME ยากิ และมีแท็บใหม่บัดเจ็ต EME จาน (จานแบบโฟกัสหลัก เกนด้วยสูตรของ PE1RKI ปรีแอมป์แบบสองภาคได้ ทรานสเวอร์เตอร์ และกำลังขับ PA); แท็บใหม่ DGRD ตามความถี่ พร้อมสัญญาณรบกวนจริงของสถานีและท้องฟ้าที่เฉลี่ยตลอดลำคลื่น ใช้ทั่วทั้งโปรแกรม; สายโคแอกซ์คำนวณด้วยสูตร α = k1·√f + k2·f จากข้อมูลในเอกสารข้อมูล รวมถึงที่ 902 และ 1296 MHz; รูปแบบใหม่ของปุ่มควบคุมในทุกแท็บ; ในตำแหน่งสดและ +- 24h มีทูลทิปบนเคอร์เซอร์สีแดงและเส้นสีแดงของ DX ที่เวลาของเคอร์เซอร์; คู่มือปรับปรุงหลังการเปรียบเทียบแหล่งข้อมูล (การสูญเสียตามเส้นทางในแต่ละแบนด์ เกณฑ์ของ Q65-60B และ Q65-60C เกนจากพื้นตามการวัดของ IK1UWL คอนเน็กเตอร์ Dgrd ของโปรแกรมอื่น จานที่สูงกว่า 432 MHz); แพ็กเกจสำหรับทุกสถาปัตยกรรม (Windows x64 และ x86, Linux x64, arm64 และ arm, macOS Apple Silicon และ Intel); ขอบคุณ Robert HA5OLA แบนด์ที่สูงกว่า 432 MHz ยังอยู่ระหว่างการพัฒนาให้สมบูรณ์
- 1.5 - แท็บใหม่เรดาร์ GRAVES ในกลุ่มการติดต่อ: ดวงจันทร์ในลำคลื่นของเรดาร์พร้อมเซกเตอร์และขั้น ช่วงเวลาร่วมกับคุณ ดอปเพลอร์และการหน่วงของเอคโค่ การผ่านครั้งถัดไปของลำคลื่นบนดวงจันทร์ ท้องฟ้าที่มองจาก GRAVES การจำลอง 24 ชั่วโมง UTC พร้อมรายละเอียด 10 วินาทีถัดไป คำแนะนำในการฟังเอคโค่ และแหล่งที่มา; รายการสถานีที่ใช้งานอยู่ในรูปแบบ JSON และข้อความสำหรับ LunaCalc Mobile ด้วย; สองภาษาใหม่ คือภาษาเดนมาร์กและภาษาตากาล็อก (รวม 28 ภาษา) พร้อมคู่มือ
- 1.4 - สถานีที่ใช้งานอยู่: ช่องสัญญาณเรียกขานของ DX มีกรอบสีส้มหากสถานีนั้นเขียนในแชต EME ของ N0UK ในช่วง 90 วันที่ผ่านมา พร้อมวันที่ของข้อความล่าสุดในทูลทิป; แบบอักษร พร้อมฟอนต์แนะนำ 10 แบบสำหรับ Windows, Linux และ macOS ที่ทดสอบทีละแท็บ; แพ็กเกจสำหรับ Windows 32 บิต และสำหรับ Raspberry Pi (arm64); ทรงกลมฟ้าพร้อมกรอบเส้นประสีม่วงรอบพื้นที่ที่ชี้ได้; ระยะทางและ Dgrd พร้อมวันที่ใช้ได้วันที่สี่ และเลือกวันได้ด้วยการคลิกในกราฟ; ช่องตัวเลขมีกรอบมุมมนและลูกศรวางซ้อนกัน; ปุ่มของหน้าต่างโต้ตอบอยู่ที่ขอบ (ซ้าย กลาง ขวา); กรอบคำขอบคุณเต็มความกว้าง; ในหน้าต่างแคบ การคำนวณเชิงลึกแสดงเป็นสองบรรทัด และไม่มีข้อความใดอยู่ใต้ปุ่ม
- 1.3 - เก้าภาษาใหม่: ดัตช์ เอสโตเนีย ลัตเวีย ลิทัวเนีย สวีเดน นอร์เวย์ ไอซ์แลนด์ ฮีบรู และอูรดู (รวม 26 ภาษา) พร้อมคู่มือ; สัญญาอนุญาตและ README ในทุกภาษา สัญญาอนุญาตในภาษาของตัวติดตั้ง; ปุ่ม GRAVES; คอนเน็กเตอร์ใน TX และคอนเน็กเตอร์ใน RX ในบัดเจ็ต EME (คำแนะนำของ NJ9R); ตัวแบ่งที่ลากได้ระหว่างคอลัมน์ซ้ายกับแผนภาพของบัดเจ็ต EME; ช่องชั้นสีเทาในสำรวจสิ่งกีดขวางของฉัน; ดีบักสูตรเปลี่ยนเป็นตรวจสอบการคำนวณ และ ABOUT & CREDITS เปลี่ยนเป็นข้อมูลและเครดิต; บททางเทคนิคของคู่มือการใช้งานในภาษาเบงกาลี อาหรับ และตุรกี; แก้ไขชุดสีพาสเทล; หน้าต่าง CALL3.TXT ปิดเองหลังการอัปเดต; เว้นระยะปุ่มของกล่องโต้ตอบ

- beta 19 - ชื่อหน้าต่างแสดงสัญญาณเรียกขานของผู้ใช้; ไม่มี locator หรือสัญญาณเรียกขานเริ่มต้น; การตั้งค่าอยู่ในโฟลเดอร์ของโปรแกรม; ลำดับแท็บใหม่; คำแนะนำพร้อมพารามิเตอร์ทั้งหมด MNR และ CFOM; แท็บ experimental-EXCEL; ดาวน์โหลดล็อกจาก LoTW; ABOUT & CREDITS; ภาษาฮินดี เกาหลี และอินโดนีเซีย
- beta 18 - บัดเจ็ต EME: แบนด์วิดท์สูงสุด 3000 Hz ค่าสัญญาณรบกวนอยู่ข้างเกน ทรานสเวอร์เตอร์ไม่ถูกนำมาคำนวณเมื่อเกนเป็น 0 อุณหภูมิสายอากาศ Tant (ตาราง VE7BQH); การตั้งค่าทั่วไปในแท็บการติดตาม; ดวงจันทร์ข้างขึ้นแบบเบลอเป็นพื้นหลังของหน้าจอหลัก
- beta 17 - กรอบ "การคำนวณเชิงลึก" ในการติดตาม (คอลัมน์ตั้งแต่ Dpol เป็นต้นไป แถวกลางของบัดเจ็ต EME แท็บสัญญาณรบกวนจากดวงอาทิตย์); S/N โดยประมาณในหน้าจอหลัก; ปุ่ม "เลือกแบนด์" พร้อมแบนด์ตั้งแต่ 50 MHz ถึง 122 GHz
- beta 14 - ชื่อใหม่ YAEC - Yet Another EME Calc; ส่วนติดต่อผู้ใช้ใน 8 ภาษา (อังกฤษ อิตาลี เยอรมัน ฝรั่งเศส สเปน โปรตุเกส จีน ญี่ปุ่น) โดยมีภาษาอังกฤษเป็นภาษาเริ่มต้น; สัญญาณเรียกขานในชื่อหน้าต่าง
- beta 13 - แก้ไขข้อผิดพลาดการคอมไพล์ CS0051 (การเข้าถึงฟังก์ชัน Friis)
- beta 12 - ค่าสัญญาณรบกวนของวิทยุคำนวณจาก MDS ด้วยแบนด์วิดท์ที่ผู้ใช้เลือก (เท่ากับที่ใช้คำนวณ S/N)
- beta 11 - ออกแบบหน้าจอหลักการติดตามใหม่ (locator ของฉันและของ DX ความถี่ วันที่และเวลา แอซิมัทและมุมเงยของฉันและของ DX ข้อมูลที่เป็นประโยชน์อื่น ๆ); locator และความถี่คัดลอกไปยังทุกแท็บโดยอัตโนมัติ; ค่าสัญญาณรบกวนของเครื่องรับด้วยสูตรของ Friis; ระยะทางและ Dgrd ถึง 61 วัน; สัญญาณเรียกขานในการตั้งค่าทั่วไป; คำแนะนำเรื่อง ALC ในคำแนะนำ
- beta 10 - แท็บการติดตาม; kHz ตั้งแต่ 000 ถึง 999; วันในสัปดาห์; แบนด์วิดท์และ S/N พร้อมดวงอาทิตย์ในบัดเจ็ต; เกนจากพื้นแบบ BETA; การสูญเสียของสายต่อระหว่างทรานสเวอร์เตอร์กับวิทยุ; ธีมมืดและฟอนต์; Dgrd หนึ่งเดือนพร้อมจันทร์ดับ; LoTW เป็นสีเขียว; แท็บคำแนะนำ; หน้าต่างเริ่มต้นและการยืนยันการออก
- beta 9 - ทรงกลมฟ้าในแอซิมัท/มุมเงย พร้อมขอบฟ้าแบนราบและสีของสัญญาณรบกวนจากสีน้ำเงินถึงสีแดง; แท็บระยะทางและ Dgrd; แท็บ ABOUT
- beta 6 - แท็บแผนที่ WWL และ ADIF พร้อมตาราง Maidenhead
- beta 5 - คอลัมน์สถานะถูกแทนที่ด้วยสี; ชื่อเรื่อง "จัดทำโดย Costantino IC8TEM"; รายการแบบเลื่อนลงของ kHz สำหรับความถี่ CFOM
- beta 4 - เวลาท้องถิ่นของ DX คำนวณจากตำแหน่ง; ระยะเวลาเป็นวัน; ทูลทิปของคอลัมน์; ความถี่ดอปเพลอร์และ CFOM; แท็บทรงกลมฟ้า
- beta 3 - S/N โดยประมาณในบัดเจ็ต; แท็บสัญญาณรบกวนจากดวงอาทิตย์พร้อมข้อมูล SFU จากเว็บและการเลือกสถานี RSTN
- beta 2 - แท็บบัดเจ็ต EME: EIRP การสูญเสียตามเส้นทาง สัญญาณที่รับได้ และส่วนเผื่อเหนือ MDS
- beta 1 - สถานีที่สอง (DX) ช่วงเวลาร่วม Dpol, MNR, Tsky และ Dgrd เช่นเดียวกับใน WSJT-X
