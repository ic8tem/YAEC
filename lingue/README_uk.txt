YAEC – Yet Another EME Calc 1.3
автор: Costantino IC8TEM
==========================================

Калькулятор для радіоаматорів, які працюють через EME (Земля–Місяць–Земля) у діапазонах від 50 до 432 МГц: положення Місяця та вікна наведення з урахуванням обмежень вашої антени, планування днів із найкращим Dgrd, енергетичний бюджет EME-радіолінії, шуми неба та Сонця, база даних коаксіальних кабелів і посібники з EME. Для Windows, Linux і macOS, 26 мовами.
Вихідний код і завантаження: https://github.com/ic8tem/YAEC/releases

ВСТАНОВЛЕННЯ – WINDOWS
1. Завантажте YAEC-1.3-Setup.exe зі сторінки Releases і запустіть його. Він встановлює YAEC у Документи\YAEC без прав адміністратора, зі ярликами в меню «Пуск» і на робочому столі, а також із програмою видалення.
2. Якщо з'явиться попередження SmartScreen: "More info" → "Run anyway".
3. Без встановлення: розпакуйте YAEC-1.3-windows-portable.zip у папку, до якої маєте право запису, і запустіть YAEC.exe.

ВСТАНОВЛЕННЯ – LINUX
YAEC працює в Mono — вільному середовищі виконання .NET.
- Debian, Ubuntu, Mint: завантажте yaec_1.3_all.deb і встановіть його командою
      sudo apt install ./yaec_1.3_all.deb
  (заразом встановлюється й Mono). YAEC запускається з меню застосунків або командою «yaec».
- Інші дистрибутиви: встановіть Mono (Fedora: sudo dnf install mono-complete; Arch: sudo pacman -S mono; openSUSE: sudo zypper install mono-complete), розпакуйте YAEC-1.3-linux.tar.gz і запустіть ./install.sh.

ВСТАНОВЛЕННЯ – macOS (експериментально)
1. Встановіть Mono для macOS (https://www.mono-project.com/download/stable/) і XQuartz (https://www.xquartz.org).
2. Відкрийте YAEC-1.3-macOS.dmg і перетягніть YAEC до папки «Програми». Першого разу: клацніть правою кнопкою на YAEC → «Відкрити» (застосунок не підписаний Apple).

ПЕРЕВІРКА ЗАВАНТАЖЕНИХ ФАЙЛІВ (SHA-256)
Кожен реліз містить SHA256SUMS.txt із хешем SHA-256 кожного пакета. Порівняйте його з хешем завантаженого файлу:
- Windows (PowerShell): Get-FileHash .\YAEC-1.3-Setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
Якщо значення різняться, не встановлюйте файл: завантажте його ще раз.

МОВА І ДАНІ
Мову вибирають у верхній частині головного вікна. Усі дані програми зберігаються в папці «data»: у Windows поруч із YAEC.exe, у Linux у ~/.local/share/YAEC/data, у macOS у ~/Library/Application Support/YAEC/data.
