## Note per l'installazione

- Windows: YAEC-...-windows-x64-setup.exe (installa in Documenti\YAEC, senza diritti di amministratore) oppure lo zip portatile da estrarre in una cartella dove si può scrivere; per Windows a 32 bit i file -windows-x86-, per Windows su ARM (Snapdragon) i file -windows-arm64-; per Windows 7 SP1, 8 e 8.1 i file -windows7-x64- e -windows7-x86- (serve il .NET Framework 4.8; non ancora provato).
- Linux, FreeBSD, OpenBSD e macOS: YAEC gira con Mono (sudo apt install mono-complete, sudo dnf install mono-complete, sudo pacman -S mono, sudo zypper install mono-complete); i pacchetti .deb, .rpm e Arch lo installano da soli.
- Linux (Debian, Ubuntu, Mint): yaec_..._amd64.deb, con: sudo apt install ./yaec_..._amd64.deb.
- Fedora, openSUSE: yaec-....x86_64.rpm (o .aarch64.rpm, .armv7hl.rpm), con: sudo dnf install ./yaec-....rpm oppure sudo zypper install ./yaec-....rpm.
- Arch, Manjaro, EndeavourOS, Arch Linux ARM: yaec-...-1-x86_64.pkg.tar.zst (o -aarch64), con: sudo pacman -U ./yaec-...pkg.tar.zst.
- Slackware (x86_64 e ARM64): da root installpkg yaec-...-x86_64-1_ic8tem.txz (o -aarch64-); Mono da SlackBuilds.
- Qualsiasi Linux: YAEC-...-x86_64.AppImage (o -aarch64): rendere eseguibile e avviare (con Mono installato).
- Alpine Linux (musl): YAEC-...-alpine-x64.tar.gz o -alpine-arm64.tar.gz, con Mono dai pacchetti di Alpine (non ancora provato).
- Linux, tutte le distribuzioni: YAEC-...-linux-x64.tar.gz, da estrarre; si avvia ./yaec dalla cartella estratta o si installa con ./install.sh. Linux i686: -linux-x86; FreeBSD e OpenBSD amd64: -freebsd-x64 e -openbsd-x64 (con Mono e libgdiplus, non ancora provati).
- Raspberry Pi 3/4/5: yaec_..._arm64.deb (Raspberry Pi OS 64 bit) o yaec_..._armhf.deb (32 bit); in alternativa YAEC-...-raspberry-pi-64bit.tar.gz o -32bit.tar.gz.
- Altri Linux ARM (es. Slackware ARM64, schede armv7l): YAEC-...-linux-arm64.tar.gz o -linux-armv7l.tar.gz, come il tar.gz per Linux.
- Mac (sperimentale; servono Mono per macOS e XQuartz): YAEC-...-mac-apple-silicon.dmg (M1/M2/M3/M4) o -mac-intel.dmg: aprire il .dmg e trascinare YAEC in Applicazioni; oppure YAEC-...-mac-apple-silicon-app.zip / -mac-intel-app.zip. Al primo avvio clic destro > Apri.
- Aggiornamenti automatici: YAEC controlla GitHub all'avvio e si aggiorna da solo su Windows, con gli archivi portatili, l'AppImage e l'app per Mac; i pacchetti .deb, .rpm, Arch e Slackware si aggiornano con il gestore dei pacchetti (YAEC avvisa e apre questa pagina).
