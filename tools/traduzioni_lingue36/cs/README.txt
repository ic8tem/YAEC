YAEC – Yet Another EME Calc 1.6
od Costantino IC8TEM
==========================================

Kalkulátor pro radioamatéry pracující provozem EME (Země–Měsíc–Země) od 50 MHz do 23 cm (1296 MHz): poloha Měsíce a okna zaměření v rámci limitů vlastní antény, plánování dnů s nejlepším Dgrd, energetická bilance spoje EME s anténami Yagi nebo parabolami, šum oblohy a Slunce, databáze koaxiálních kabelů a příručky o EME. Pro Windows, Linux a macOS, ve 28 jazycích. Pásma nad 432 MHz se stále dokončují, ale DGRD se již počítá správně na každém kmitočtu.
Zdrojový kód a stažení: https://github.com/ic8tem/YAEC/releases

INSTALACE – WINDOWS
1. Stáhněte YAEC-1.6-win-x64-setup.exe ze stránky Releases a spusťte jej. Nainstaluje YAEC do Documents\YAEC, bez práv správce, se zástupci v nabídce Start a na ploše a s odinstalačním programem.
2. Pokud se objeví varování SmartScreen: "Další informace" → "Přesto spustit".
3. Bez instalace: rozbalte YAEC-1.6-win-x64-portatile.zip do složky, do které můžete zapisovat, a spusťte YAEC.exe.

INSTALACE – LINUX
YAEC běží na Mono, svobodném běhovém prostředí .NET.
- Debian, Ubuntu, Mint: stáhněte yaec_1.6_amd64.deb a nainstalujte jej příkazem
      sudo apt install ./yaec_1.6_amd64.deb
  (tím se nainstaluje i Mono). YAEC spusťte z nabídky aplikací nebo příkazem "yaec".
- Ostatní distribuce: nainstalujte Mono (Fedora: sudo dnf install mono-complete; Arch: sudo pacman -S mono; openSUSE: sudo zypper install mono-complete), rozbalte YAEC-1.6-linux-x64-portatile.tar.gz (ARM: YAEC-1.6-linux-arm64-portatile.tar.gz, YAEC-1.6-linux-arm-portatile.tar.gz) a spusťte ./install.sh.

INSTALACE – macOS (experimentální)
1. Nainstalujte Mono pro macOS (https://www.mono-project.com/download/stable/) a XQuartz (https://www.xquartz.org).
2. Otevřete YAEC-1.6-osx-arm64.dmg (Apple Silicon) / YAEC-1.6-osx-x64.dmg (Intel) a přetáhněte YAEC do složky Aplikace. Poprvé: klikněte pravým tlačítkem na YAEC → Otevřít (aplikace není podepsána společností Apple).

KONTROLA STAŽENÝCH SOUBORŮ (SHA-256)
Každé vydání obsahuje SHA256SUMS.txt s hashem SHA-256 každého balíčku. Porovnejte jej s hashem staženého souboru:
- Windows (PowerShell): Get-FileHash .\YAEC-1.6-win-x64-setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
Pokud se obě hodnoty liší, soubor neinstalujte: stáhněte jej znovu.

JAZYK A DATA
Jazyk se volí v horní části hlavního okna. Všechna data programu jsou uložena ve složce "data": ve Windows vedle YAEC.exe, v Linuxu v ~/.local/share/YAEC/data, v macOS v ~/Library/Application Support/YAEC/data.
