YAEC – Yet Another EME Calc 1.6
készítette: Costantino IC8TEM
==========================================

Számítóprogram EME (Föld–Hold–Föld) forgalmat bonyolító rádióamatőröknek 50 MHz-től 23 cm-ig (1296 MHz): a Hold helyzete és az irányzási ablakok a saját antennád korlátain belül, a legjobb Dgrd-jű napok tervezése, EME összeköttetési mérleg yagikkal vagy tányérokkal, égbolti és napzaj, koaxiáliskábel-adatbázis és EME kézikönyvek. Windowsra, Linuxra és macOS-re, 28 nyelven. A 432 MHz feletti sávok kidolgozása folyamatban van, de a DGRD már minden frekvencián helyesen számítódik.
Forráskód és letöltések: https://github.com/ic8tem/YAEC/releases

TELEPÍTÉS – WINDOWS
1. Töltsd le a YAEC-1.6-win-x64-setup.exe fájlt a Releases oldalról, és futtasd. A YAEC-et a Dokumentumok\YAEC mappába telepíti, rendszergazdai jogok nélkül, parancsikonokkal a Start menüben és az asztalon, valamint eltávolítóval.
2. Ha megjelenik a SmartScreen figyelmeztetés: "További információ" → "Futtatás mindenképp".
3. Telepítés nélkül: csomagold ki a YAEC-1.6-win-x64-portatile.zip fájlt egy írható mappába, és indítsd el a YAEC.exe-t.

TELEPÍTÉS – LINUX
A YAEC a Monón fut, a szabad .NET futtatókörnyezeten.
- Debian, Ubuntu, Mint: töltsd le a yaec_1.6_amd64.deb fájlt, és telepítsd ezzel:
      sudo apt install ./yaec_1.6_amd64.deb
  (ez a Monót is telepíti). A YAEC-et az alkalmazásmenüből vagy a "yaec" paranccsal indíthatod.
- Más disztribúciók: telepítsd a Monót (Fedora: sudo dnf install mono-complete; Arch: sudo pacman -S mono; openSUSE: sudo zypper install mono-complete), csomagold ki a YAEC-1.6-linux-x64-portatile.tar.gz fájlt (ARM: YAEC-1.6-linux-arm64-portatile.tar.gz, YAEC-1.6-linux-arm-portatile.tar.gz), és futtasd a ./install.sh parancsot.

TELEPÍTÉS – macOS (kísérleti)
1. Telepítsd a Monót macOS-re (https://www.mono-project.com/download/stable/) és az XQuartzot (https://www.xquartz.org).
2. Nyisd meg a YAEC-1.6-osx-arm64.dmg (Apple Silicon) / YAEC-1.6-osx-x64.dmg (Intel) fájlt, és húzd a YAEC-et az Alkalmazások mappába. Első alkalommal: jobb kattintás a YAEC-en → Megnyitás (az alkalmazást az Apple nem írta alá).

A LETÖLTÖTT FÁJLOK ELLENŐRZÉSE (SHA-256)
Minden kiadás tartalmazza a SHA256SUMS.txt fájlt az egyes csomagok SHA-256 kivonatával. Vesd össze a letöltött fájl kivonatával:
- Windows (PowerShell): Get-FileHash .\YAEC-1.6-win-x64-setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
Ha a két érték eltér, ne telepítsd a fájlt: töltsd le újra.

NYELV ÉS ADATOK
A nyelvet a főablak felső részén lehet kiválasztani. A program minden adata a "data" mappában található: Windowson a YAEC.exe mellett, Linuxon a ~/.local/share/YAEC/data, macOS-en a ~/Library/Application Support/YAEC/data mappában.
