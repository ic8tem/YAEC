YAEC – Yet Another EME Calc 1.6
autor: Costantino IC8TEM
==========================================

Kalkulator dla krótkofalowców pracujących przez EME (Ziemia–Księżyc–Ziemia) od 50 MHz do 23 cm (1296 MHz): pozycja Księżyca i okna nakierowania w granicach ograniczeń własnej anteny, planowanie dni z najlepszym Dgrd, budżet łącza EME z antenami Yagi lub czaszami, szum nieba i Słońca, baza danych kabli koncentrycznych i podręczniki EME. Dla Windows, Linux i macOS, w 28 językach. Pasma powyżej 432 MHz są w trakcie uzupełniania, ale DGRD jest już obliczany poprawnie na każdej częstotliwości.
Kod źródłowy i pliki do pobrania: https://github.com/ic8tem/YAEC/releases

INSTALACJA – WINDOWS
1. Pobierz YAEC-1.6-win-x64-setup.exe ze strony Releases i uruchom go. Instaluje YAEC w Dokumenty\YAEC, bez uprawnień administratora, ze skrótami w menu Start i na pulpicie oraz z deinstalatorem.
2. Jeśli pojawi się ostrzeżenie SmartScreen: „Więcej informacji” → „Uruchom mimo to”.
3. Bez instalacji: rozpakuj YAEC-1.6-win-x64-portatile.zip do folderu, w którym możesz zapisywać, i uruchom YAEC.exe.

INSTALACJA – LINUX
YAEC działa na Mono, wolnym środowisku uruchomieniowym .NET.
- Debian, Ubuntu, Mint: pobierz yaec_1.6_amd64.deb i zainstaluj go poleceniem
      sudo apt install ./yaec_1.6_amd64.deb
  (instaluje to także Mono). Uruchamiaj YAEC z menu aplikacji lub poleceniem "yaec".
- Inne dystrybucje: zainstaluj Mono (Fedora: sudo dnf install mono-complete; Arch: sudo pacman -S mono; openSUSE: sudo zypper install mono-complete), rozpakuj YAEC-1.6-linux-x64-portatile.tar.gz (ARM: YAEC-1.6-linux-arm64-portatile.tar.gz, YAEC-1.6-linux-arm-portatile.tar.gz) i uruchom ./install.sh.

INSTALACJA – macOS (eksperymentalna)
1. Zainstaluj Mono dla macOS (https://www.mono-project.com/download/stable/) i XQuartz (https://www.xquartz.org).
2. Otwórz YAEC-1.6-osx-arm64.dmg (Apple Silicon) / YAEC-1.6-osx-x64.dmg (Intel) i przeciągnij YAEC do Aplikacji. Za pierwszym razem: kliknij YAEC prawym przyciskiem myszy → Otwórz (aplikacja nie jest podpisana przez Apple).

SPRAWDZANIE POBRANYCH PLIKÓW (SHA-256)
Każde wydanie zawiera SHA256SUMS.txt ze skrótem SHA-256 każdego pakietu. Porównaj go ze skrótem pobranego pliku:
- Windows (PowerShell): Get-FileHash .\YAEC-1.6-win-x64-setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
Jeśli obie wartości się różnią, nie instaluj pliku: pobierz go ponownie.

JĘZYK I DANE
Język wybiera się u góry okna głównego. Wszystkie dane programu są przechowywane w folderze "data": w Windows obok YAEC.exe, w Linux w ~/.local/share/YAEC/data, w macOS w ~/Library/Application Support/YAEC/data.
