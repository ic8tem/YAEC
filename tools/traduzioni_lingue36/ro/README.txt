YAEC – Yet Another EME Calc 1.6
de Costantino IC8TEM
==========================================

Un calculator pentru radioamatorii care lucrează EME (Pământ–Lună–Pământ) de la 50 MHz la 23 cm (1296 MHz): poziția Lunii și ferestrele de orientare în limitele propriei antene, planificarea zilelor cu cea mai bună Dgrd, bugetul legăturii EME cu antene yagi sau parabolice, zgomotul cerului și al Soarelui, o bază de date a cablurilor coaxiale și manuale EME. Pentru Windows, Linux și macOS, în 28 de limbi. Benzile de peste 432 MHz sunt încă în curs de finalizare, dar DGRD este deja calculat corect la orice frecvență.
Sursa și descărcările: https://github.com/ic8tem/YAEC/releases

INSTALARE – WINDOWS
1. Descărcați YAEC-1.6-win-x64-setup.exe de pe pagina Releases și rulați-l. Instalează YAEC în Documente\YAEC, fără drepturi de administrator, cu scurtături în meniul Start și pe desktop, precum și un program de dezinstalare.
2. Dacă apare avertismentul SmartScreen: "More info" → "Run anyway" („Mai multe informații” → „Rulează oricum”).
3. Fără instalare: extrageți YAEC-1.6-win-x64-portatile.zip într-un dosar în care puteți scrie și porniți YAEC.exe.

INSTALARE – LINUX
YAEC rulează pe Mono, mediul de execuție .NET liber.
- Debian, Ubuntu, Mint: descărcați yaec_1.6_amd64.deb și instalați-l cu
      sudo apt install ./yaec_1.6_amd64.deb
  (aceasta instalează și Mono). Porniți YAEC din meniul de aplicații sau cu comanda "yaec".
- Alte distribuții: instalați Mono (Fedora: sudo dnf install mono-complete; Arch: sudo pacman -S mono; openSUSE: sudo zypper install mono-complete), extrageți YAEC-1.6-linux-x64-portatile.tar.gz (ARM: YAEC-1.6-linux-arm64-portatile.tar.gz, YAEC-1.6-linux-arm-portatile.tar.gz) și rulați ./install.sh.

INSTALARE – macOS (experimental)
1. Instalați Mono pentru macOS (https://www.mono-project.com/download/stable/) și XQuartz (https://www.xquartz.org).
2. Deschideți YAEC-1.6-osx-arm64.dmg (Apple Silicon) / YAEC-1.6-osx-x64.dmg (Intel) și trageți YAEC în Applications. Prima dată: clic dreapta pe YAEC → Open (aplicația nu este semnată de Apple).

VERIFICAREA FIȘIERELOR DESCĂRCATE (SHA-256)
Fiecare release conține SHA256SUMS.txt cu amprenta SHA-256 a fiecărui pachet. Comparați-o cu amprenta fișierului descărcat:
- Windows (PowerShell): Get-FileHash .\YAEC-1.6-win-x64-setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
Dacă cele două valori diferă, nu instalați fișierul: descărcați-l din nou.

LIMBĂ ȘI DATE
Limba se alege în partea de sus a ferestrei principale. Toate datele programului sunt păstrate în dosarul "data": pe Windows lângă YAEC.exe, pe Linux în ~/.local/share/YAEC/data, pe macOS în ~/Library/Application Support/YAEC/data.
