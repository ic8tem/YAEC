YAEC – Yet Another EME Calc 1.6
โดย Costantino IC8TEM
==========================================

โปรแกรมคำนวณสำหรับนักวิทยุสมัครเล่นที่ติดต่อแบบ EME (โลก–ดวงจันทร์–โลก) ตั้งแต่ 50 MHz ถึง 23 cm (1296 MHz): ตำแหน่งดวงจันทร์และช่วงเวลาที่ชี้ได้ภายในขีดจำกัดของสายอากาศของคุณเอง การวางแผนวันที่มี Dgrd ดีที่สุด งบลิงก์ EME สำหรับสายอากาศยากิหรือจาน สัญญาณรบกวนจากท้องฟ้าและดวงอาทิตย์ ฐานข้อมูลสายโคแอกเชียล และคู่มือ EME สำหรับ Windows, Linux และ macOS ใน 28 ภาษา แบนด์ที่สูงกว่า 432 MHz ยังอยู่ระหว่างการพัฒนาให้สมบูรณ์ แต่ DGRD คำนวณได้ถูกต้องแล้วในทุกความถี่
ซอร์สโค้ดและการดาวน์โหลด: https://github.com/ic8tem/YAEC/releases

การติดตั้ง – WINDOWS
1. ดาวน์โหลด YAEC-1.6-win-x64-setup.exe จากหน้า Releases แล้วเรียกใช้ โปรแกรมจะติดตั้ง YAEC ไว้ใน Documents\YAEC โดยไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ พร้อมทางลัดในเมนู Start และบนเดสก์ท็อป และตัวถอนการติดตั้ง
2. หากมีคำเตือนของ SmartScreen: "More info" → "Run anyway"
3. หากไม่ต้องการติดตั้ง: แตกไฟล์ YAEC-1.6-win-x64-portatile.zip ลงในโฟลเดอร์ที่คุณเขียนได้ แล้วเรียกใช้ YAEC.exe

การติดตั้ง – LINUX
YAEC ทำงานบน Mono ซึ่งเป็นรันไทม์ .NET แบบฟรี
- Debian, Ubuntu, Mint: ดาวน์โหลด yaec_1.6_amd64.deb แล้วติดตั้งด้วย
      sudo apt install ./yaec_1.6_amd64.deb
  (คำสั่งนี้จะติดตั้ง Mono ด้วย) เรียกใช้ YAEC จากเมนูแอปพลิเคชันหรือด้วยคำสั่ง "yaec"
- ดิสทริบิวชันอื่น: ติดตั้ง Mono (Fedora: sudo dnf install mono-complete; Arch: sudo pacman -S mono; openSUSE: sudo zypper install mono-complete) แตกไฟล์ YAEC-1.6-linux-x64-portatile.tar.gz (ARM: YAEC-1.6-linux-arm64-portatile.tar.gz, YAEC-1.6-linux-arm-portatile.tar.gz) แล้วเรียกใช้ ./install.sh

การติดตั้ง – macOS (ทดลอง)
1. ติดตั้ง Mono สำหรับ macOS (https://www.mono-project.com/download/stable/) และ XQuartz (https://www.xquartz.org)
2. เปิด YAEC-1.6-osx-arm64.dmg (Apple Silicon) / YAEC-1.6-osx-x64.dmg (Intel) แล้วลาก YAEC ไปไว้ใน Applications ครั้งแรก: คลิกขวาที่ YAEC → Open (แอปไม่ได้ลงนามโดย Apple)

การตรวจสอบไฟล์ที่ดาวน์โหลด (SHA-256)
ทุก release มีไฟล์ SHA256SUMS.txt พร้อมค่าแฮช SHA-256 ของแต่ละแพ็กเกจ เปรียบเทียบกับค่าแฮชของไฟล์ที่ดาวน์โหลด:
- Windows (PowerShell): Get-FileHash .\YAEC-1.6-win-x64-setup.exe -Algorithm SHA256
- Linux: sha256sum -c --ignore-missing SHA256SUMS.txt
- macOS: shasum -a 256 -c --ignore-missing SHA256SUMS.txt
หากค่าทั้งสองไม่ตรงกัน อย่าติดตั้งไฟล์นั้น: ให้ดาวน์โหลดใหม่

ภาษาและข้อมูล
เลือกภาษาได้ที่ด้านบนของหน้าต่างหลัก ข้อมูลทั้งหมดของโปรแกรมเก็บไว้ในโฟลเดอร์ "data": บน Windows อยู่ข้าง YAEC.exe บน Linux อยู่ใน ~/.local/share/YAEC/data บน macOS อยู่ใน ~/Library/Application Support/YAEC/data

สัญญาอนุญาต
YAEC ไม่มีค่าใช้จ่าย; ข้อความของสัญญาอนุญาตอยู่ในไฟล์ LICENSE_th.txt และในแท็บสัญญาอนุญาตของโปรแกรม ในกรณีมีข้อสงสัย ให้ยึดฉบับภาษาอิตาลี (LICENZA.txt)

ประวัติเวอร์ชัน
เวอร์ชันก่อน 1.0 เรียกว่า beta
- 1.6 - แบนด์ 902 MHz และ 23 cm (1296 และ 1298 MHz) ทั่วทั้งโปรแกรม โดยมีทุกแบนด์ในรายการเลือก MHz; แท็บ Budget EME เปลี่ยนเป็น Budget EME ยากิ และมีแท็บใหม่ Budget EME จาน (จานแบบ prime focus อัตราขยายด้วยสูตรของ PE1RKI ปรีแอมป์สองภาคได้ ทรานสเวอร์เตอร์และกำลังขับของ PA); แท็บใหม่ DGRD ตามความถี่ ด้วยสัญญาณรบกวนจริงของสถานีและท้องฟ้าเฉลี่ยทั่วลำคลื่น ใช้ทั่วทั้งโปรแกรม; สายโคแอกเชียลคำนวณด้วยสูตร α = k1·√f + k2·f จากข้อมูลในเอกสารข้อมูล รวมถึงที่ 902 และ 1296 MHz; สไตล์ใหม่ของตัวควบคุมในทุกแท็บ; ในตำแหน่งสดและ +- 24h มีคำอธิบายบนเคอร์เซอร์สีแดง และเส้นสีแดงของ DX ณ เวลาของเคอร์เซอร์; ปรับปรุงคู่มือหลังเปรียบเทียบแหล่งที่มา (การสูญเสียของเส้นทางแต่ละแบนด์ เกณฑ์ของ Q65-60B และ Q65-60C, ground gain ตามการวัดของ IK1UWL ขั้วต่อ Dgrd ของโปรแกรมอื่น จานที่สูงกว่า 432 MHz); แพ็กเกจสำหรับทุกสถาปัตยกรรม (Windows x64 และ x86, Linux x64, arm64 และ arm, macOS Apple Silicon และ Intel); ขอบคุณ Robert HA5OLA แบนด์ที่สูงกว่า 432 MHz ยังอยู่ระหว่างการพัฒนาให้สมบูรณ์
- 1.5 - แท็บใหม่เรดาร์ GRAVES ในกลุ่มการติดต่อ: ดวงจันทร์ในลำคลื่นของเรดาร์พร้อมเซกเตอร์และขั้น ช่วงเวลาร่วมกับคุณ Doppler และการหน่วงของเอคโค การผ่านดวงจันทร์ครั้งถัดไปของลำคลื่น ท้องฟ้าที่มองจาก GRAVES การจำลอง 24 ชั่วโมง UTC พร้อมรายละเอียด 10 วินาทีข้างหน้า คำแนะนำในการรับฟังเอคโค และแหล่งที่มา; รายชื่อสถานีที่ใช้งานในรูปแบบ JSON และข้อความสำหรับ LunaCalc Mobile ด้วย; สองภาษาใหม่ เดนมาร์กและตากาล็อก (รวม 28 ภาษา) พร้อมคู่มือ
- 1.4 - สถานีที่ใช้งาน: ช่องสัญญาณเรียกขานของ DX มีขอบสีส้มหากสถานีนั้นเขียนในแชต EME ของ N0UK ใน 90 วันที่ผ่านมา พร้อมวันที่ของข้อความล่าสุดในคำอธิบาย; ชนิดแบบอักษรพร้อมแบบอักษรแนะนำ 10 แบบสำหรับ Windows, Linux และ macOS ทดสอบทีละแท็บ; แพ็กเกจสำหรับ Windows 32 บิต และ Raspberry Pi (arm64); ทรงกลมฟ้าพร้อมกรอบเส้นประสีม่วงรอบบริเวณที่คุณชี้ได้; ระยะทางและ Dgrd พร้อมวันใช้งานได้วันที่สี่ และเลือกวันได้ด้วยการคลิกในกราฟ; ช่องตัวเลขมีกรอบมนและลูกศรซ้อนบนล่าง; ปุ่มของกล่องโต้ตอบชิดขอบ (ซ้าย กลาง ขวา); กรอบคำขอบคุณเต็มความกว้าง; ในหน้าต่างแคบ การคำนวณเชิงลึกแสดงเป็นสองบรรทัด และไม่มีข้อความใดอยู่ใต้ปุ่ม
- 1.3 - เก้าภาษาใหม่: ดัตช์ เอสโตเนีย ลัตเวีย ลิทัวเนีย สวีเดน นอร์เวย์ ไอซ์แลนด์ ฮีบรู และอูรดู (รวม 26 ภาษา) พร้อมคู่มือ; สัญญาอนุญาตและ README ในทุกภาษา สัญญาอนุญาตในภาษาของตัวติดตั้ง; ปุ่ม GRAVES; ขั้วต่อใน TX และขั้วต่อใน RX ใน Budget EME (คำแนะนำของ NJ9R); ตัวแบ่งที่ลากได้ระหว่างคอลัมน์ซ้ายกับแผนผังของ Budget EME; ช่องชั้นสีเทาในสำรวจสิ่งกีดขวางของฉัน; DEBUG FORMULE เปลี่ยนเป็นตรวจสอบการคำนวณ และ ABOUT & CREDITS แปลแล้วในทุกภาษา; บทเชิงเทคนิคของคู่มือการใช้งานในภาษาเบงกาลี อาหรับ และตุรกี; แก้ไขชุดสีพาสเทล; หน้าต่าง CALL3.TXT ปิดเองหลังอัปเดต; เว้นระยะปุ่มของกล่องโต้ตอบ
- 1.2.1 - หน้าติดต่อผู้เขียนและคำขอบคุณเปิดได้ถูกต้องอีกครั้งบน Linux และ macOS; การอ้างอิงสำหรับทรานสเวอร์เตอร์ชี้ไปที่ § 1.7.1
- 1.2 - Budget EME พร้อมตัวบ่งชี้ EIRP ของฉัน EIRP ของ DX การสูญเสียของเส้นทาง และ S/N ทั้งสองทิศทาง (รวมดวงอาทิตย์); สูตรในเอกสาร Word ขนาดเดียวกันทั้งหมด อยู่ภายในขอบ; ปุ่มทึบและรายการเลือกแบบแบนขอบมนในทุกชุดสี; ชุดสีพาสเทลแปดชุด; ช่องค่าที่มีลูกศรอยู่ข้างกัน; สามวันที่ดีที่สุดเรียงตามวันที่; พื้นหลังท้องฟ้าแบบเบลอ; แปล DEBUG FORMULE แล้ว; คู่มือทฤษฎีและคำแนะนำเกี่ยวกับ EME พร้อมคำแนะนำของ Relu NJ9R (GRAVES, การชี้, ขั้วต่อ, อัตราขยายของสายอากาศ, JT65B และ MAP65, รีเลย์โพลาไรเซชัน) หัวข้อใหม่เกี่ยวกับการรับครั้งแรกและแชตผ่านอินเทอร์เน็ต และตารางของ VE7BQH ในคำนำ; คำขอบคุณถึง NJ9R การระลึกถึง IK1UWL และผู้เขียนบทความ ฮาร์ดแวร์ และซอฟต์แวร์ พร้อมคำอธิบายผลงานของพวกเขา
- 1.1 - ตำแหน่งสดและ +- 24h (เดิมคือการติดตาม) แสดงได้ทั้งอดีตและอนาคต: เลือกวันจากปฏิทินและเวลาโดยลากเส้นสีแดง ความถี่ในกรอบเอคโคและความถี่; ช่องสัญญาณเรียกขานของ DX พร้อม CALL3.TXT ที่ดาวน์โหลดจาก W7GJ และ WSJT-X Improved แล้วรวมกัน เสนอ locator และคัดลอกไปยังโฟลเดอร์ของ WSJT-X; ระยะทางและ Dgrd ไม่มีอันดับ ซ้อนเดคลิเนชัน แถวมีสีเหมือนกราฟ และเลือกแสดงชั่วโมงใช้งานได้เป็นสีเขียวได้; ช่องทำเครื่องหมายในสไตล์ของโปรแกรม; สายเรียงตามเส้นผ่านศูนย์กลางในรายการเลือก และตามชื่อ ผู้ผลิต และชนิดในตาราง พร้อมแหล่งที่มาที่แปลแล้ว; Budget EME มีเฉพาะโหมด 60 s (JT65, Q65-60A, Q65-60B, Q65-60C) และแผนผังระบบที่ปรับตามข้อความ; คู่มือการใช้งานพร้อมภาพรวมของทุกหน้าจอ; ทฤษฎีและคำแนะนำเกี่ยวกับ EME พร้อมคำนำของผู้เขียน การนับเลขเริ่มจาก 1 และสูตรของสัญญาณรบกวนดวงอาทิตย์; HTTPS บน Linux และ macOS ด้วยใบรับรองของระบบ
